## 10. КРИТЕРИИ ЗАВЕРШЕНИЯ ЭТАПОВ

### ЭТАП 1 — IMAGE LAYER (AI PROVIDER)

Считается завершённым, если:

- [ ] ComfyUI provider делает HTTP запросы (/prompt → /history)
- [ ] реально получает изображение от ComfyUI
- [ ] возвращает валидный ResolvedImage
- [ ] при недоступности ComfyUI НЕ роняет pipeline
- [ ] fallback (artwork / placeholder) работает
- [ ] quick_card_smoke проходит без падений

---

### ЭТАП 2 — СТАБИЛИЗАЦИЯ

Считается завершённым, если:

- [ ] resolver корректно выбирает источник (AI / artwork / fallback)
- [ ] metadata корректно передаётся downstream
- [ ] нет падений при 10+ прогонах подряд
- [ ] изображения генерируются стабильно
- [ ] нет битых или пустых результатов

---

### ЭТАП 3 — PRODUCTION READY

Считается завершённым, если:

- [ ] batch (10+ карточек подряд) работает
- [ ] pipeline (image → card → video → publish) проходит полностью
- [ ] нет критических ошибок
- [ ] все этапы пайплайна связаны

---

### ЭТАП 4 — КАЧЕСТВО

Считается завершённым, если:

- [ ] карточки читаемые
- [ ] тексты не ломаются
- [ ] нет визуального мусора
- [ ] изображения нормального качества

---

### ЭТАП 5 — МАСШТАБ

Считается завершённым, если:

- [ ] ежедневная генерация без ручных правок
- [ ] pipeline стабилен на дистанции
- [ ] нет деградации качества
