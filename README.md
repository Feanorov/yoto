# Telegram Deal Bot

Новий бот для Telegram-каналу з акціями та роздачами Steam/Epic.

Що вміє:
- сканує до 2000 акційних позицій Steam за цикл;
- знаходить поточні роздачі Epic Games;
- зберігає історію цін і не дублює однакові офери;
- репостить офери при покращенні знижки та за день до кінця дуже сильних знижок;
- робить окрему "гру дня" з безкоштовних роздач;
- генерує картки зображень для постів;
- публікує пости у випадкові інтервали від 20 до 90 хвилин;
- підтримує ручний календар фестивалів і великих розпродажів.

## Швидкий старт

1. Створити `.env` за зразком `.env.example`.
2. Встановити залежності з `requirements.txt`.
3. Запустити:

```powershell
python -m dealbot.main --once
python -m dealbot.main --send-test
python -m dealbot.main
```

## Режими запуску

- `--once` — один цикл відбору та постановки в чергу.
- `--send-test` — підготувати і відправити один тестовий пост у канал.
- `--reset-memory` — очистити історію публікацій і чергу.

## Календар фестивалів

Події лежать у `data/calendar_events.json`. Сюди можна додавати великі фестивалі, сезонні розпродажі й інші інфоприводи.
